What each method remembers

● SGD uses the current gradient.

● AdaGrad accumulates squared gradients; its effective steps tend to shrink.

● RMSProp tracks a recent average of squared gradients.

● Adam tracks both gradient momentum and a recent average of squared gradients.

Model details and limitations

Two trainable parameters are optimized directly on an illustrative mathematical loss surface. This is not neural network training. Each method uses the same base learning rate, starting point and step budget; defaults such as momentum coefficients remain fixed. Equal numeric learning rates do not guarantee a fair real-world benchmark. Contours show loss height; dots mark current parameter values.
